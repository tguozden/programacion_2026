## Datos como texto

Es común recibir datos numéricos como cadenas de texto. Para trabajar con ellos hay que *parsearlos*: convertirlos a un tipo de datos adecuado.

Por ejemplo, dada la cadena de caracteres `cadena`:
```python
cadena = '1, 2\n3, 4'
filas = cadena.split('\n')     # ['1, 2', '3, 4'] (separa filas)
xy = filas[0].split(', ')      # ['1', '2']       (obtiene cada número por separado)
tupla = (float(xy[0]), float(xy[1]))   # (1.0, 2.0)
```

La distancia euclidiana de un punto `(x, y)` al origen es:

$$d = \sqrt{x^2 + y^2}$$
